# フロントとCloudflare APIの接続

## ローカル起動

リポジトリ直下 `C:\github_use\HackStage` で実行します。

```powershell
npm install
npm run d1:migrate:local --workspace @nodobito/api
npm run seed:daily:local --workspace @nodobito/api
npm run dev:api
```

別のターミナルで以下を実行します。

```powershell
npm run dev:mobile -- --go --lan --clear
```

`apps/mobile/.env.local` の `EXPO_PUBLIC_API_BASE_URL` は `http://<PCのWi-Fi IPv4>:8787` にします。PCとスマホは同じWi-Fiに接続してください。変更後はMetroを再起動します。Expo GoでMetroのQRを読み込みます。スマホのブラウザから `http://<PCのWi-Fi IPv4>:8787/health/ready` を開き、`ok:true`が返ることも確認してください。

`npm run dev:api` はCloudflare版を起動します。Express版は比較用に `npm run dev:api:legacy` で起動できますが、今回のモバイル接続先ではありません。本番は追加マイグレーションの適用とWorkerの再デプロイが必要です。この変更では本番リソースを操作していません。

## 接続した画面

| 画面 | API連携 |
|---|---|
| 探す | 候補取得、スワイプでいいね・見送り保存、相互いいねでマッチ |
| 届いたいいね | 実際の受信一覧、いいね返し、辞退 |
| トーク一覧 | マッチ一覧、最終メッセージ、未読表示、手動更新 |
| チャット | DB履歴、送信、過去履歴、既読保存、安全警告 |
| 今日のお題 | 日本時間の当日お題、回答保存・再表示、会話から達成状態を計算 |
| 相手プロフィール | 実プロフィール、サーバーで計算した段階、公開同意・取り消し |
| マイページ | 写真取得、編集、公開範囲、検索条件、連絡先非表示、通報・ブロック・解除、写真／会話／アカウント削除、予定登録・双方確認・到着・キャンセル |

主要画面はデモデータを読み込みません。0件と通信失敗を区別して表示し、失敗した送信は入力を残します。チャットは約4秒、マッチ一覧・お題・相手プロフィールは約5秒、受信いいねは約10秒ごとのポーリングです。画面を離れた時・バックグラウンド時は停止します。Push通知やSSEへの接続は含みません。

本人確認・年齢確認の審査待ちはCloudflare版から廃止しました。18歳以上の生年入力は残しています。既存の確認テーブルは過去データ保全のため削除しません。追加テーブルは別名にし、以前の検証ブランチのローカルDBとも衝突させません。

## 2アカウントでの操作確認

1. Aを登録し、プロフィールを保存する。写真は撮影後に初期公開画像を確認して登録する。
2. ログアウトしてBを登録し、Aにいいねを送る。
3. Aでログインし直す。「届いたいいね」にBが出ることを確認し、いいねを返す。
4. トークでメッセージを送る。Bでログインし直し、履歴と未読表示を確認して返信する。2台あれば並行して確認できる。
5. 今日のお題を開き、回答を送る。開き直して回答と達成状態が残ることを確認する。「相手から返信」は当日の相手のメッセージ、「質問」は自分の当日メッセージの `?` / `？` を判定する。
6. マイページで公開設定や検索条件を保存して開き直す。地域の表示は初期状態ではOFF。地域指定の検索では、地域非公開のユーザーを除外する。
7. 予定を登録し、A・B双方で確認する。詳細な場所は双方の確認・共有同意が揃うまで表示されない。共有先はマッチ相手のみ。信頼する第三者への共有リンクは未対応。
8. ブロック後に相手のトーク・画像にアクセスできなくなることを確認する。写真削除・会話削除・退会は削除してよいテストデータだけで試す。

## 写真と公開段階

新規撮影は長辺1280ピクセルに縮小し、サーバーで5段階のJPEGを生成します。受信端末には許可された切り出し画像のみを送ります。原画像を先にダウンロードして覆う方式にはしません。以前の未切り出し画像は所有者以外に配信しないため、既存ユーザーは再撮影が必要です。

切り出しは固定の撮影位置に基づき、顔や首の自動検出ではありません。撮影後のプレビューで首周りが写っていること・顔が含まれていないことを確認し、不適切なら撮り直します。

公開条件は双方の相互発言日数が3日・7日・14日・30日。段階2以降は共同回答1件・3件・7件も必要です。その条件に達した後に写真の所有者が相手ごとに追加公開へ同意します。同意は30日間、取り消しは指定段階以上を失効させます。同日の連投や画面のタップだけでは段階は進みません。

## 検証コマンド

```powershell
npm run test:mobile-integration --workspace @nodobito/api
npm run typecheck:cloudflare --workspace @nodobito/api
npm run typecheck --workspace mobile
npm run lint --workspace mobile
```

結合テストは起動中のローカルWorkersを使用し、一時アカウントで登録・画像切り出し・いいね・チャット・権限・既読・デイリー・予定・ブロックを確認します。途中の公開条件テストでは、そのテストで作ったメッセージだけの日時を変更して日数の経過を再現します。終了時には作成したアカウントと、その実行で作ったお題を削除します。本番URLは受け付けません。

実機のタッチ操作・カメラ位置・撮影プレビューは上記手順で別途確認してください。本番の画像処理にはWorkersのCPU／メモリ制限もあるため、デプロイ先での実画像・負荷検証は別途必要です。
